## 1. ปุ่มส่งงานมองไม่เห็นบนไอโฟน — เดาผิด 3 รอบ

### สาเหตุที่แท้จริง

`.app-body` (กล่องเนื้อหาที่มีสกอลบาร์ของตัวเอง) มี `-webkit-overflow-scrolling: touch` อยู่
บน iOS มันทำสองอย่างพร้อมกัน:

1. **กลายเป็นกรอบอ้างอิงของลูกที่เป็น `position: fixed`** — `.modal-bg { inset: 0 }` เลยกาง
   เท่ากรอบเนื้อหา ไม่ใช่เท่าจอ
2. **สร้าง stacking context ใหม่** — `z-index: 50` ของกล่องถูกขังอยู่ข้างใน สู้ `z-index: 20`
   ของแถบเมนูล่างซึ่งเป็นพี่น้องกับ `.app-body` ไม่ได้

ผลคือปุ่มท้ายกล่องไปนอนอยู่ใต้แถบเมนูล่าง มองไม่เห็นและกดไม่ได้

### สิ่งที่เดาผิดไปก่อนหน้า (บันทึกไว้กันทำซ้ำ)

| รอบ | เดาว่า | ทำอะไร | ผล |
|---|---|---|---|
| v24 | `env(safe-area-inset-bottom)` ไม่ได้เผื่อ | flex column + footer ตรึงก้นกล่อง | แย่ลง ปุ่มจมถาวร เลื่อนตามไปก็ไม่ได้ |
| v26 | Safari เก่าไม่รู้จัก `dvh` | เปลี่ยนเป็น `%` + sticky footer | ยังไม่เห็น |
| v28 | ขอบล่างของจอไว้ใจไม่ได้ | ย้ายปุ่มไปบนสุด | เห็นปุ่ม แต่ยังไม่ได้แก้ต้นเหตุ |

**บทเรียน: ขอภาพหน้าจอตั้งแต่รายงานครั้งแรก** ภาพเดียวเห็นสาเหตุใน 10 วินาที
(ฉากมืดหลังกล่องไม่คลุมแถบหัวกับแถบเมนู = กล่องไม่ได้อิงจอจริง) ที่เดามา 3 รอบเสียไป 3 deploy

### ที่แก้จริง (v29)

- `components.jsx` — `Modal` แขวนที่ `document.body` ผ่าน `createPortal` หลุดจากกรอบ `.app-body`
- `styles.css` — เอา `-webkit-overflow-scrolling: touch` ออกทั้งหมด (iOS 13+ เลื่อนลื่นเองอยู่แล้ว)
- ปุ่มลงมือหลักย้ายมาไว้บนสุดใต้ชื่อเรื่อง (`action` prop) และคงไว้แม้แก้ต้นเหตุแล้ว

## 2. ผู้ปกครองดูรูปผลงานไม่ได้ (v25)

`uploadPhoto_` เก็บลิงก์เป็น `drive.google.com/uc?export=view&id=…` ซึ่ง Google ปิดการฝังข้ามเว็บ
ไปแล้ว `<img>` ได้ HTML แทนไฟล์ภาพ → กล่องว่าง

- `Drive.gs` — `drivePhotoSrc_()` แปลงเป็น `drive.google.com/thumbnail?id=…&sz=w1600`
  (endpoint เดียวที่ยังฝังได้) และ `driveOpenUrl_()` สำหรับเปิดไฟล์เต็ม
- `driveFileId_()` ดึง id ออกจากลิงก์ได้ทุกแบบ → **งานเก่ากลับมาเห็นรูปโดยไม่ต้องแก้ข้อมูลในชีต**
- `components.jsx` — `<Photo>` กดที่รูปเปิดเต็มใน Drive ได้ ถ้ารูปโหลดไม่ขึ้นจะกลายเป็นปุ่มลิงก์แทน

## 3. เลือกไฟล์จากในเครื่องไม่ได้ (v27)

`<input type="file" capture="environment">` บังคับ iOS ให้เปิดกล้องอย่างเดียว
เอา `capture` ออก → ขึ้นเมนูครบ คลังรูป / ถ่ายรูป / เลือกไฟล์

## 4. "งานตั้งไว้ 10 แต่ได้จริง 5" (v26)

ไม่ใช่บั๊ก แต่สูตรทำงานเงียบเกินไป — `ฐาน × คุณภาพ × ส่งสาย × ตัวคูณช่วงเวลา × ส่วนแบ่งทีม` ปัดลง
ที่ได้ 5 มาจากค่าตั้งต้นคุณภาพ 80% × ส่วนแบ่งทีม 70% = 56% ของ 10

- หน้าตรวจงานโชว์**ที่มาของตัวเลขทีละบรรทัด**และยอดจริงบนปุ่ม (เดิมบอกแค่ "%")
- แถบเลื่อนคุณภาพ → **ปุ่มกด 5 ระดับ** (แถบเลื่อนบนมือถือแตะพลาดแล้วกระโดดไปกลางแถบ = 50%)
- ค่าตั้งต้นคุณภาพ 80% → **100%** (ตั้งงานไว้ 10 กดผ่านเฉยๆ ต้องได้ 10)

## 5. แต้มค้างในแอปเด็ก (v30)

ไม่มีแคชฝั่งเซิร์ฟเวอร์ — แอปเด็กดึงข้อมูลตอนเปิดหน้าครั้งเดียวแล้วไม่ดึงซ้ำ

- `useLoad` ดึงใหม่อัตโนมัติเมื่อกลับมาดูหน้าจอ (`visibilitychange` + `pageshow` ที่ `persisted`)
  โดยไม่ล้างข้อมูลเดิมทิ้ง หน้าจอจึงไม่กระพริบเป็นสปินเนอร์
- ปุ่ม 🔄 บนแถบหัวของแอปเด็ก (bump nonce → remount หน้าที่เปิดอยู่)

⚠️ ผลข้างเคียงที่ตามมาแก้ทีหลัง (v34): ฟอร์มที่ seed ค่าจาก `useLoad` จะโดนเขียนทับตอน refetch
ที่พิมพ์ค้างไว้หายหมด — ดูข้อ 8

## 6. กระดานผู้นำไม่ขยับตามการปรับแต้ม (v31)

`weekPointsByChild_` นับเฉพาะงานที่ผ่านการตรวจ ไม่นับตาราง `PointAdjustments`

- นับแต้มที่ผู้ปกครองปรับเองในช่วงนั้นด้วย (มีผลทั้งกระดานผู้นำและ HP บอส)
- ติดลบแล้วตรึงที่ 0
- แยก `dateStrOf_()` ออกมา กัน `new Date('')` เข้า `formatDate` แล้วพังทั้งคำขอ

## 7. เก็บแต้มรายคนจริง (v32)

เดิมเก็บแค่ `pointsPerPerson` (ยอดกลางของงาน) แต่แต่ละคนได้ไม่เท่ากันเพราะโบนัสสตรีค
กระดานผู้นำกับเลเวลจึงต่ำกว่าที่ได้จริง

- คอลัมน์ใหม่ `Submissions.awards` = `chd_x:12,chd_y:8` (**ต่อท้ายเท่านั้น** — ทั้งระบบอ่านเขียน
  ชีตตามลำดับคอลัมน์ใน `SCHEMA`)
- `Db.ensureCols_()` ต่อคอลัมน์ + เขียนหัวตารางให้อัตโนมัติตอนเขียนครั้งแรก ไม่ต้องรัน `setup()` เอง
- `parseAwards_()` / `awardFor_()` งานเก่าที่ยังไม่มีคอลัมน์นี้ถอยไปใช้ยอดกลาง
- ใช้กับกระดานผู้นำ, HP บอส, **XP/เลเวล**, และแท็บสถานะของเด็ก

## 8. บอส 3 ตัว + หน้าตั้งค่ากติกา (v33, v34)

### บอสประจำเดือน

เปลี่ยนจากตัวเดียวรายสัปดาห์ → **3 ตัวเรียงกันรายเดือน** ล้มตัวก่อนหน้าแล้วตัวถัดไปถึงโผล่
ดาเมจส่วนเกินไหลต่อไปตัวถัดไป · เลือด = แต้มที่ทุกคนในบ้านทำได้รวมกันตั้งแต่วันที่ 1 ของเดือน
· รางวัลแจกครั้งเดียวต่อตัวต่อเดือนต่อคน (`questAwarded_('boss'+slot, 'yyyy-MM')`)
· เว้นชื่อว่าง = ปิดบอสตัวนั้น (`bossState_` คืน `null` ถ้าไม่ได้ตั้งสักตัว)

### แท็บ ⚙️ กติกา

`parent.config.get` / `parent.config.save` + `EDITABLE_CONFIG` + `validateConfig_`
(ตรวจค่าฝั่งเซิร์ฟเวอร์ ข้อความไทย) · `setConfigMany_()` อ่านชีตครั้งเดียว เขียนเฉพาะคีย์ที่เปลี่ยน

แก้ได้: `latePercent`, `teamPercent`, `streakBonusTiers`, `streakShieldCost/Max`,
`dailyQuestTarget/Bonus`, `xpPerLevel`, และบอสทั้ง 3 ตัว (ชื่อ/อีโมจิ/เลือด/รางวัล)
**ตั้งใจไม่เปิดให้แก้:** `timezone`, `sessionHours`, `streakBadges` — แก้ผิดแล้วพังทั้งระบบ

### บั๊กฟอร์มโดนเขียนทับ (v34)

ผลพ่วงจากข้อ 5 — `useEffect(() => setForm(data), [data])` เจอ refetch แล้วล้างที่พิมพ์ค้างไว้
แก้ด้วย `dirtyRef` (รับค่าจากเซิร์ฟเวอร์เฉพาะตอนไม่มีของแก้ค้าง) + แถบเตือน "ยังไม่ได้บันทึก"
+ ปุ่มบอกสถานะ (`บันทึกแล้ว ✓` / `บันทึกกติกา`)
